# Digital Transformation Assessment

Use the **business-consulting:digital-transformation** skill to assess digital maturity and build a transformation roadmap.

## Analysis Steps

1. **Digital Maturity Assessment** — Score the organization across 8 dimensions (1–5 scale):
   | Dimension | Current Level | Target Level | Gap | Priority |
   |-----------|:---:|:---:|:---:|:---:|
   | Strategy & Vision | | | | |
   | Customer Experience | | | | |
   | Operations & Processes | | | | |
   | Technology & Architecture | | | | |
   | Data & Analytics | | | | |
   | Organization & Culture | | | | |
   | Innovation & Agility | | | | |
   | Ecosystem & Partnerships | | | | |

2. **AI & Automation Opportunity Scan** — Identify processes suitable for automation. Score each on feasibility × impact. Present top 10 opportunities with estimated ROI.

3. **Technology Stack Assessment** — Evaluate current technology landscape. Classify applications as: Retain, Re-platform, Replace, or Retire. Identify consolidation opportunities and cost savings.

4. **Data Strategy Review** — Assess data governance, quality, architecture, and analytics capabilities. Identify data monetization opportunities and quick wins.

5. **Build vs. Buy vs. Partner** — For top 3 technology gaps, evaluate build, buy, and partner options with TCO comparison and recommendation.

6. **Digital Roadmap** — Create a phased roadmap:
   - **Phase 1 (0–6 months):** Quick wins, foundation building, governance setup
   - **Phase 2 (6–18 months):** Core transformation initiatives, capability building
   - **Phase 3 (18–36 months):** Advanced capabilities, scaling, optimization
   Include dependencies, investment requirements, and expected outcomes per phase.

7. **Investment Summary** — Total investment required, phased over 3 years, with expected ROI and payback period.

## Output Requirements

- Present maturity scores as a scorecard table
- Quantify all automation opportunities with dollar impact
- Include a visual roadmap (timeline table with swim lanes by workstream)
- End with top 5 strategic recommendations ranked by impact and urgency
