# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2025-02-28

### Added

- **16 consulting skills** covering the full consulting workflow:
  - Market Research — TAM/SAM/SOM, PESTEL, industry analysis
  - Competitive Analysis — competitor profiling, VRIO, strategic group mapping
  - Financial Analysis — DCF, LBO, comps, unit economics, SaaS metrics
  - Strategy Frameworks — SWOT/TOWS, BCG, Ansoff, Porter's, Blue Ocean, Wardley Mapping
  - Operations Analysis — process mapping, Lean/Six Sigma, KPI design
  - Benchmarking — peer comparison, maturity assessment, gap analysis
  - Data Analysis — Pareto, cohort, regression, RFM segmentation
  - Deliverable Creation — Pyramid Principle, slide storyboarding, report writing
  - Change Management — stakeholder mapping, ADKAR, Kotter's 8-Step
  - Pricing Strategy — value-based pricing, elasticity, SaaS pricing
  - M&A Strategy — target screening, synergy modeling, integration planning
  - Customer Insights — journey mapping, personas, churn analysis, CLV
  - Digital Transformation — maturity assessment, AI/automation, build vs buy
  - Risk Management — ERM frameworks, Monte Carlo, BCP
  - Talent Strategy — workforce planning, compensation benchmarking, retention
  - Innovation Strategy — 70/20/10 portfolio, stage-gate, design thinking

- **24 slash commands** for quick access:
  - 20 analysis commands (one per skill + extras)
  - 3 cross-skill playbooks (`/growth-strategy`, `/turnaround-playbook`, `/ma-assessment`)
  - 1 utility command (`/set-context`)

- **5 industry overlays** with pre-built metrics and benchmarks:
  - Technology/SaaS, Healthcare, Financial Services, Consumer/Retail, Industrial/Manufacturing

- **48 reference files** with detailed guides, templates, and worked examples

- **SessionStart hook** that configures Claude as a strategy consultant

- **16 consulting-grade Python chart recipes** with professional styling
