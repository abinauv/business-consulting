# M&A Integration Playbook

## Day 1 Readiness Checklist

### Legal & Regulatory
- [ ] Transaction legally closed, all regulatory approvals received
- [ ] Entity registrations updated
- [ ] New legal entity structure documented
- [ ] Employment agreements and NDAs executed
- [ ] IP assignments and license transfers completed
- [ ] Insurance policies updated or new coverage in place

### HR & People
- [ ] All employees notified of acquisition (compliant with labor laws)
- [ ] Retention bonus agreements signed for critical talent
- [ ] Benefits continuity confirmed (health insurance, 401k, PTO)
- [ ] Org charts published for first 90 days
- [ ] Payroll migration plan in place (or interim payroll confirmed)
- [ ] Employee FAQ document distributed
- [ ] HR policies aligned or interim policies communicated
- [ ] New employee badges/access credentials issued

### IT & Systems
- [ ] Email and communication access maintained/migrated
- [ ] Network connectivity established
- [ ] Critical business systems accessible
- [ ] Security protocols implemented (SSO, VPN, endpoint protection)
- [ ] Data backup and disaster recovery confirmed
- [ ] Phone systems connected or forwarded

### Finance
- [ ] Bank accounts transitioned or dual-signature implemented
- [ ] Chart of accounts mapping documented
- [ ] Financial reporting process for combined entity defined
- [ ] Signing authority updated for payments
- [ ] Tax withholding and reporting updated
- [ ] Accounts payable/receivable process continuity confirmed

### Communications
- [ ] Internal announcement ready (CEO message, FAQs, talking points)
- [ ] External announcement ready (press release, customer letters, social media)
- [ ] Customer communication sent (relationship continuity, no service disruption)
- [ ] Supplier notification sent (contract continuity, payment terms)
- [ ] Regulatory bodies notified (where required)
- [ ] Website updated (if immediate rebrand)
- [ ] Analyst/investor communication prepared

### Operations
- [ ] Customer orders and fulfillment process uninterrupted
- [ ] Supply chain and vendor payments continuing
- [ ] Key contracts reviewed for change-of-control clauses
- [ ] Critical operational processes documented and accessible
- [ ] Emergency contacts and escalation paths shared

## First 100 Days Plan

### Phase 1: Stabilize (Days 1–30)

**Objective:** Maintain business continuity, retain key people, establish governance

| Workstream | Key Activities | Milestones | Owner |
|-----------|---------------|-----------|-------|
| **Leadership** | Announce leadership structure, begin 1:1 meetings with key leaders | Org chart published, leadership aligned on 100-day priorities | CEO / CPO |
| **Talent** | Identify critical talent, issue retention packages, conduct stay conversations | 100% retention of critical talent identified | CHRO |
| **Customers** | CEO outreach to top 20 customers, account manager continuity plan | Zero customer churn from announcement | CRO |
| **Operations** | Maintain all operations, identify quick wins, freeze non-essential changes | Operations KPIs stable vs. pre-close | COO |
| **Finance** | Financial reporting cadence, combined budget, synergy tracking setup | First combined financial report | CFO |
| **Communications** | Weekly internal updates, bi-weekly town halls, feedback channel | Communication cadence established | Comms Lead |
| **Culture** | Cultural assessment survey, team-building events, values alignment workshop | Cultural baseline assessment complete | CHRO |

### Phase 2: Integrate (Days 31–100)

**Objective:** Begin functional integration, capture quick-win synergies, align processes

| Workstream | Key Activities | Milestones | Owner |
|-----------|---------------|-----------|-------|
| **Organization** | Implement new structure below leadership, role clarity, reporting lines | All roles staffed, no open critical positions | CHRO |
| **Processes** | Harmonize critical processes (order-to-cash, procure-to-pay, hire-to-retire) | Top 5 processes harmonized | COO |
| **Technology** | Begin system integration planning, quick wins (email, collaboration) | Email/calendar unified, integration roadmap approved | CTO |
| **Sales** | Unified go-to-market, combined pipeline, cross-sell training | Combined sales playbook launched | CRO |
| **Synergies** | Execute quick-win synergies (headcount, procurement, G&A) | 30–40% of Year 1 synergy target achieved | CFO |
| **Brand** | Brand strategy decision (rebrand, co-brand, preserve), begin execution if rebranding | Brand decision made, execution plan approved | CMO |
| **Customers** | Account planning for combined customer base, identify cross-sell opportunities | Top 50 accounts have combined account plans | CRO |

### Phase 3: Optimize (Days 101–365)

**Objective:** Deep integration, scale synergies, cultural unification

| Workstream | Key Activities | Milestones | Owner |
|-----------|---------------|-----------|-------|
| **Systems** | Major system migrations (ERP, CRM, HRIS), data integration | Core systems consolidated or interfaced | CTO |
| **Synergies** | Execute complex synergies (facility consolidation, IT migration) | 70–80% of Year 1 target, 100% of cost synergies identified | CFO |
| **Products** | Combined product roadmap, integrated R&D, portfolio rationalization | Unified product strategy published | CPO |
| **Culture** | Culture integration programs, leadership development, employer brand | Culture survey shows improvement vs. Day 30 baseline | CHRO |
| **Performance** | Combined performance management, compensation harmonization | Single performance review process | CHRO |

## Integration Management Office (IMO)

### IMO Structure

```
Executive Steering Committee
(CEO, CFO, CHRO, CTO — Monthly review)
        |
IMO Leader (full-time, VP-level)
        |
├── Synergy Lead (tracks financial value capture)
├── Communications Lead (internal + external)
├── Workstream Coordinators:
│   ├── Finance
│   ├── IT
│   ├── HR & Culture
│   ├── Sales & Marketing
│   ├── Operations
│   └── Legal & Compliance
└── PMO Support (tracking, reporting, risk management)
```

### IMO Governance

| Meeting | Frequency | Attendees | Agenda |
|---------|-----------|----------|--------|
| Steering Committee | Monthly | C-suite | Synergy tracking, major decisions, risk escalation |
| IMO Leadership | Weekly | IMO leader + workstream leads | Progress, blockers, cross-workstream dependencies |
| Workstream standups | 2x/week | Workstream team | Task tracking, issue resolution |
| Synergy review | Bi-weekly | CFO, synergy lead, workstream leads | Synergy realization vs. plan |
| Town hall update | Monthly | All employees | Progress, wins, next milestones |

### Decision Rights Framework

| Decision Type | Example | Decision Maker | Approval Required |
|-------------|---------|:---:|:---:|
| **Strategic** | Brand strategy, org structure, platform choice | Steering Committee | CEO |
| **Financial** | Synergy targets, budget allocation (>$500K) | CFO | Steering Committee |
| **Operational** | Process standardization, policy harmonization | Workstream Lead | IMO Leader |
| **People** | Hiring, retention packages (>$100K), severance | CHRO | Steering Committee |
| **Tactical** | Day-to-day execution, vendor management (<$100K) | Workstream Coordinator | Workstream Lead |

## Cultural Integration Approaches

| Approach | When to Use | Risk Level | Example |
|----------|------------|:----------:|---------|
| **Absorption** | Target is much smaller, acquirer's culture is clearly stronger | Medium | Large company acquires small startup; startup adopts acquirer's processes |
| **Preservation** | Target's culture is the reason for acquisition (e.g., innovation) | Low (short-term) | Tech company acquires creative studio; studio operates independently |
| **Symbiosis** | Best of both cultures should be combined | High (hardest to execute) | Merger of equals; deliberately design new shared culture |
| **Transformation** | Both cultures need to change (often in turnaround situations) | Very High | Both organizations undergo fundamental change together |

### Cultural Compatibility Assessment

Assess alignment across 8 dimensions:

| Dimension | Acquirer | Target | Gap | Risk Level |
|-----------|---------|--------|:---:|:----------:|
| Decision speed (fast ↔ deliberate) | | | | |
| Hierarchy (flat ↔ hierarchical) | | | | |
| Risk tolerance (bold ↔ cautious) | | | | |
| Collaboration (siloed ↔ cross-functional) | | | | |
| Customer focus (internal ↔ customer-obsessed) | | | | |
| Innovation (incremental ↔ disruptive) | | | | |
| Work style (structured ↔ flexible) | | | | |
| Communication (formal ↔ informal) | | | | |

**Large gaps (>3 points) = high integration risk.** Design specific interventions for each high-gap dimension.

## Clean Room Protocols

For pre-close planning when companies are still competitors:

**Rules:**
- Only approved clean room team members can access shared information
- All information sharing must comply with antitrust/competition law
- No competitively sensitive pricing, customer, or strategy data before close
- Use outside counsel to review all information requests
- Document all information shared and restrict access
- Clean room data cannot be used for day-to-day competitive decisions

**What CAN be shared in clean room:**
- Organizational structure and headcount (aggregate)
- IT systems and contracts list
- Real estate portfolio
- Benefits and compensation structure (aggregate)
- Integration planning scenarios

**What CANNOT be shared until close:**
- Individual customer data
- Pricing strategies and specific pricing data
- Competitive intelligence or strategic plans
- Individual employee compensation
- Specific pipeline or sales forecasts
